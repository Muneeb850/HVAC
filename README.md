## 🌟 Key Architectural Highlights

### 1. Dual Combo Color Scheme (Light & Dark Harmony)
In accordance with your design directive, this website is neither entirely dark nor entirely light. Instead, it utilizes a deliberate, high-contrast visual rhythm:
- **Hero & Navigation (Dark Obsidian Slate `#090E17` / `#05080C`):** Cinematic luxury feel featuring glowing cyan/aquamarine fluid particles, copper highlights, and real-time Denver/Aurora telemetry.
- **Homeowner Emergency Triage Wizard (Crisp Porcelain Light `#F4F5F8`):** Clean, high-legibility interface presenting immediate first-aid containment protocols and urgency levels.

- **3D WebGL Pipe & Hydro-Jetting Lab (Deep Hydro Dark `#090E17`):** Interactive Three.js WebGL simulation allowing users to control water pressure up to 4,000 PSI, toggle hot water thermal modes, and CCTV diagnostics.
- **Front Range Service Cost & Financing Estimator (Porcelain Light & Dark HUD):** Dynamic calculation of pricing and Wells Fargo monthly installments based on home size and add-ons.
- **Colorado Dispatch Telemetry & Radar (Obsidian Slate `#090E17`):** Live municipal radar tracking active vans across Denver, Aurora, Boulder, Parker, Centennial, and Lakewood.
- **Verified Google & Yelp Reviews (Crisp Ceramic Light `#FAFAFB`):** Authentic customer testimonials extracted from `onenationco.com` (featuring reviews praising Gerardo and the team).
- **Wells Fargo Financing & Guarantees (Dark Slate `#090E17`):** Official 0% APR financing portal integration and interactive FAQ accordion.
- **Footer (Deep Obsidian `#05080C`):** Full contact directory, Aurora headquarters address, and Colorado Master Plumber license verification.

## 💧 WebGL & Advanced Animation Features
- **Interactive Three.js Hydro-Fluid Canvas:** A custom WebGL particle engine running in the Hero that reacts dynamically to cursor movement with harmonic fluid waves and kinetic repulsion.
- **Interactive 3D WebGL Pipe Bore Simulator:** A 3D cutaway industrial pipe model rendered in Three.js with real-time particle fluid dynamics, adjustable pressure slider (500 to 4,000 PSI), mode switches (Hydro-Jetting, Hot Water Thermal, CCTV scan), and 360° mouse drag rotation.
- **Interactive Before/After CCTV Scanner:** Dual-view clip-path comparison slider with live telemetry readout.
- **Web Audio UI Sound Effects:** Built-in subtle UI click feedback generated via the browser's native Web Audio API (with an instant mute/unmute toggle in the navbar).
- **Celebratory Confetti Engine:** Multi-stage confetti celebration triggered upon confirmed booking dispatch.

## 🚀 How to Run the Website Locally

### Option A: Quick Double-Click (Windows)
Double-click the `start.bat` file located in this directory.

### Option B: Using Terminal Commands
1. Start the local development server:
   ```bash
   npm run dev
   ```
2. Open your browser to the URL displayed in the terminal (default: `http://localhost:3000`).

### Option C: Build and Preview Production
```bash
npm run build
npm run preview
```
The static production assets are compiled in the `dist/` directory and ready for instant deployment to Vercel, Netlify, Cloudflare Pages, or traditional hosting.
